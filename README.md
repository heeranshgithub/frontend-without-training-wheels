# Frontend Without Training Wheels

A responsive single-page web application built using only **HTML, CSS, and JavaScript** — no frameworks, no libraries.

## 🚀 Overview

This project was built as part of a frontend challenge to focus on core web fundamentals without relying on tools like React or Tailwind CSS.

The goal was to implement a pixel-accurate UI from a Figma design while maintaining clean structure, responsiveness, and performance.

## 🛠️ Tech Stack

- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, responsive design)
- Vanilla JavaScript (DOM manipulation, interactions)

## ✨ Features

- Fully responsive layout
- Clean and semantic HTML structure
- Modular and maintainable CSS
- Interactive UI elements using vanilla JavaScript

## 📁 Project Structure

```
my-project/
├── index.html            # Main HTML file
├── styles.css            # CSS styles
├── script.js             # JavaScript logic
└── README.md             # Project documentation
```

## 🎯 Key Learnings

- Building UI without framework abstractions
- Managing layout and responsiveness from scratch
- Writing structured, scalable CSS
- Handling DOM interactions manually

## ▶️ Getting Started

Simply open `index.html` in your browser.

No build step or dependencies required.

## 📌 Notes

This project intentionally avoids frameworks to strengthen understanding of core frontend concepts.
